## 2. 🔴 Kritis

### K1 — Dobel-submit tombol "Bayar" tanpa guard in-flight *(diverifikasi auditor utama)*
`case 'save-sale-print'` (`js/app.js:601-605`) memanggil `window.simpanPenjualan('ask')` tanpa disable tombol/flag. `simpanPenjualan` full-async (kas gate → cek stok per item → lisensi → tulis DB) dan **tidak punya flag in-flight**; cart baru dikosongkan di akhir (`js/pos.js:673`). Dobel tap cepat = dua run paralel yang sama-sama lolos cek cart/stok → **2 record penjualan, stok terkurang 2×, uang dobel tercatat**. Di jalur held, run kedua `payHeldSync` throw "bukan held" → fallback membuat **penjualan baru lagi** (`js/pos.js:645-653`, `js/pos.sync.js:157-161`).
**Fix:** guard in-flight di awal `simpanPenjualan` (return awal bila sedang jalan) + disable tombol Bayar saat proses; reset di `finally`.

## 4. 🟢 Info (hardening & kebersihan kode)

1. Timer auto-slide carousel tidak didaftar-kan ke `registerCleanup` — interval terus jalan no-op setelah meninggalkan Beranda (`js/carousel.js:116-121`).
2. `escapeHtml` terduplikasi di `helpers.js:5-35` dan `helpers.pure.js:6-35` — dua implementasi berisiko divergen saat patch keamanan.
3. `close-held-list` punya fallback `classList.remove('show')` yang membypass `closeModal()` (focus-trap cleanup tak jalan) — `js/app.js:561-568`.
4. Dobel-tap "Buka Kas" bisa membuat 2 shift (baca-then-write tanpa guard; hanya shift terbaru dipakai) — `js/kas.js:163-193, 69-81`.
5. `totalModal` di checkout tanpa fallback `|| 0` (NaN bila data lama/import tanpa field) — `js/pos.js:576` vs `:57`.
6. Dead code berbuga: `getDebouncedPosSearch` tak dipakai + closure mereferensi `args` tak terdefinisi (`js/pos.js:294-306`); `setCustomDate` laporan tak punya pemanggil nyata (`js/laporan.js:889`).
7. Serial lisensi dapat dipalsukan offline (validasi HMAC lokal + salt fallback hardcode) — **keputusan desain yang diketahui**; mitigasi: sync cloud mendegradasi `active`→`trial` bila row cloud hilang (`js/license.sync.js:411-424`), jalur online wajib lewat RPC `device_assign`.
8. Perbandingan signature serial non-constant-time (`js/license.logic.js:262`); backup lama tanpa `_signature` diterima dengan warning (`js/backup.js:265-268`) — settings/license tetap tak ikut restore.
9. CSP `style-src 'unsafe-inline'` + `img-src https:` longgar — keduanya terdokumentasi sadar (`index.html:12-16`); `script-src 'self'` ketat.
10. Link `wa.me` footer tanpa `target`/`rel` (`index.html:315`); `i.qty` laporan disuntik tanpa escape (numerik dari alur normal) — `js/laporan.js:536`.
11. Fail `sw.js` precache `addAll` ditelan diam (`sw.js:253-255`) — first-load offline bisa kehilangan sebagian shell.
