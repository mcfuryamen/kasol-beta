# 14 Script Video — Kaki5 (siap rekam)

## Aturan rekam (baca sekali, berlaku semua)

- **Vertikal 9:16**, 15–35 detik. Hook = teks besar di layar pada 2 detik pertama.
- Rekam **layar HP asli** pakai screen recorder bawaan + suara lo ngomong (atau musik + teks).
- Nyalakan **auto-caption** di TikTok (mayoritas orang nonton tanpa suara).
- 1 video = upload ke TikTok + IG Reels + YT Shorts, caption beda dikit (lihat `03`).
- Jangan sebut fitur yang gak ada. Semua script di bawah pakai fitur asli kaki5.
- Ganti semua `[placeholder]` sebelum rekam.

---

### S1 — Demo input 3 barang (A)
- **Hook (teks):** "Warung lo bisa pakai kasir kayak minimarket. Gratis coba."
- **Aksi layar:** buka kaki5 → halaman POS → tap 3 produk → keranjang jalan totalnya → tap selesai → struk muncul.
- **VO/teks:** "Tinggal tap barangnya, totalnya jalan sendiri. Gak perlu alat apa-apa, cukup HP."
- **CTA:** "Komen 'KASIR' nanti gue kirim link cobain gratis."
- **Durasi:** 15–20 dtk.

### S2 — Catat di kertas = untung bocor (B)
- **Hook:** "Untung warung lo sering ilang? Ini salah satu penyebabnya."
- **Aksi layar:** foto/coretan buku catatan karbol (rekam 2 detik) → cut ke kaki5, buka **Laporan**.
- **VO:** "Catat di kertas itu gak kelihatan untungnya. Di sini langsung kelihatan tiap hari."
- **CTA:** "Coba gratis, link di bio."
- **Durasi:** 15–20 dtk.

### S3 — Tutup buku 3 menit (A)
- **Hook:** "Tutup buku warung: 3 menit. Bukan 3 jam."
- **Aksi layar:** buka **Kas** → tutup kas → ringkasan uang masuk, keluar, **laba** muncul.
- **VO:** "Tiap malem tap satu tombol, tau deh hari ini untung apa rugi."
- **CTA:** "Link di bio, gratis cobain."
- **Durasi:** 15–20 dtk.

### S4 — Build in public: setahun bikin, ini jujurnya (C)
- **Hook:** "Gue bikin aplikasi kasir sendiri. Setahun. Ini jujurnya."
- **Aksi layar:** rekam wajah 5 detik → potongan layar coding/screenshot app → akhiri app jalan di HP.
- **VO:** "Setahun gue bangun aplikasi kasir buat pedagang. Uda ada yang pakai, tapi jualannya masih susah. Gue bakal dokumenterin di sini — yang jujur, bukan yang manis."
- **CTA:** "Follow kalau mau lihat gimana nasib dev solo di Indonesia."
- **Durasi:** 25–35 dtk. *(Konten story begini yang paling gampang dapet komen empati + share.)*

### S5 — Untung hari ini kelihatan (A)
- **Hook:** "Modal 500 rebu, jualan 800 — untung berapa? Kebanyakan pedagang gak tau."
- **Aksi layar:** buka **Laporan** → scroll laporan harian (pakai data dummy yang masuk akal).
- **VO:** "Gak cukup tau omzet. Yang penting untungnya. Di sini otomatis."
- **CTA:** "Komen 'KASIR' buat link trial."
- **Durasi:** 15–25 dtk.

### S6 — HP lama pun jadi kasir (B)
- **Hook:** "HP Android apa aja bisa jadi mesin kasir. Beneran."
- **Aksi layar:** buka kaki5 di HP lama/layar kecil (kalau gak ada, emulator dengan resolusi rendah).
- **VO:** "Gak perlu beli mesin. Gak perlu printer yang mahal. HP seadanya udah cukup."
- **CTA:** "Link di bio."
- **Durasi:** 15 dtk.

### S7 — Internet mati, jualan jalan (A)
- **Hook:** "Internet warung lo lemot? Gak masalah."
- **Aksi layar:** nyalakan **mode pesawat** → tetap input 2 transaksi sukses → matikan mode pesawat.
- **VO:** "Aplikasi ini jalan total tanpa internet. Data aman di HP, ke-backup kalau online."
- **CTA:** "Gratis coba, link di bio."
- **Durasi:** 20 dtk.

### S8 — Kertas vs app (B)
- **Hook:** "Beda warung yang catat kertas vs yang pakai app. Bulan akhir."
- **Aksi layar:** split layar / potongan: kertas coretan gak jelas → kaki5 laporan laba rapi.
- **VO:** "Bukan soal rajin. Soal kelihatan. Yang gak kelihatan, gak bisa diperbaiki."
- **CTA:** "Komen 'KASIR'."
- **Durasi:** 15–20 dtk.

### S9 — Harga ojol otomatis (A) — nembak warung makan
- **Hook:** "Jualan di GoFood/GrabFood tapi untungnya beda-beda? Ini solusinya."
- **Aksi layar:** POS → pilih produk → tampilkan **harga ojol** → transaksi masuk dengan harga ojol.
- **VO:** "Harga ojol beda sama harga warung? Di sini udah diatur otomatis, gak perlu mikir."
- **CTA:** "Buat yang jualan makanan: link di bio."
- **Durasi:** 20–25 dtk. *(Niche ini kompetisinya jauh lebih sepi.)*

### S10 — Cerita pelanggan pertama (C)
- **Hook:** "Orang pertama yang bayar aplikasi gue. Ini ceritanya."
- **Aksi layar:** screenshot testimoni/WA (minta izin dulu!) + screenshot app dia pakai.
- **VO:** "Ini user pertama gue yang beneran bayar. Dari dia gue tau aplikasi ini kepake beneran, bukan cuma proyek."
- **CTA:** "Mau jadi user berikutnya? Link di bio."
- **Durasi:** 25–30 dtk.

### S11 — HP hilang ≠ data hilang (A)
- **Hook:** "HP ilang = data warung ilang? Kalo pakai ini, gak."
- **Aksi layar:** Pengaturan → **Backup** → backup jalan ke cloud.
- **VO:** "Data ke-backup otomatis pas online. HP ganti, data balik."
- **CTA:** "Link di bio."
- **Durasi:** 15 dtk.

### S12 — Jawab 5 ketakutan (B)
- **Hook:** "5 alasan pedagang gak mau pakai app kasir. Gue jawab satu-satu."
- **Aksi layar:** teks slide cepat (1 slide = 1 jawaban) + potongan layar pendukung:
  1. "Mahal" → `[HARGA]` **sekali bayar**, bukan langganan.
  2. "Ribet" → setup 5 menit, tombolnya dikit.
  3. "Susah diisi" → bisa dibantu input produk (jasa lo).
  4. "Internet?" → jalan total offline.
  5. "Data aman?" → di HP lo sendiri + backup cloud.
- **CTA:** "Ada pertanyaan lain? Komen."
- **Durasi:** 30–35 dtk.

### S13 — Cara mulai trial 5 menit (A)
- **Hook:** "Cara mulai pakai kasir gratis, dalam 5 menit."
- **Aksi layar:** buka browser → `[URL-KAKI5]` → install/tambah ke home screen → trial jalan → input 1 transaksi.
- **VO:** "Gak perlu daftar ribet. Buka, cobain. Kalo cocok baru ngomongin harga."
- **CTA:** "Link juga ada di bio."
- **Durasi:** 25–30 dtk.

### S14 — Recap 14 hari (C)
- **Hook:** "14 hari dokumenterin jualan aplikasi gue sendiri. Ini hasilnya."
- **Aksi layar:** wajah + angka jujur di layar (views, DM, trial) + potongan video terbaik.
- **VO:** "Belum jutaan, tapi mulai jalan. next target: [target]. Lo jualan apa? komen di bawah — siapa tau gue bikinin sesuatu buat lo."
- **CTA:** "Follow buat 14 hari berikutnya."
- **Durasi:** 25–35 dtk.
