2026-08-22 — HOTFIX v1.0.15 (SW v70): Perbaikan CSP yang merusak layout.
Masalah: meta CSP memakai nonce placeholder ("__CSP_NONCE__") → Chrome memblokir
semua inline style (382 titik: kartu statistik putih, overlay kehilangan posisi
fixed) dan inline onload → css/style.css (media="print") tidak pernah aktif di
layar → seluruh breakpoint tablet/desktop mati sejak v54 (2026-08-17).
Perbaikan:
1. CSP: script-src 'self' (tanpa nonce), style-src 'self' 'unsafe-inline'.
2. style.css dimuat sebagai stylesheet blocking biasa (trik media=print dihapus).
3. Script nonce-replacement & console.log dead code dihapus; dev SW-unregister
   dipindah ke js/dev-unregister-sw.js (inline script kini dilarang CSP).
4. CACHE_NAME SW → v70, cacheBust app.js → ?v=70.
