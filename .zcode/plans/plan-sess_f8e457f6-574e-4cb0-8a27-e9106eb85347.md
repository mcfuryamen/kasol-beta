# Plan Perbaikan HOTFIX P0 — Pulihkan Layout kaki5 (CSP Bug)

**Scope:** Paket A (Hotfix saja) + strategi CSP pragmatis, sesuai pilihan user.
**Target:** mengembalikan 100% tampilan yang saat ini rusak di Chrome modern (inline style diblokir + style.css mati), tanpa refactor. Estimasi 1–2 jam.

## Perubahan File

### 1. `index.html` — inti hotfix
- **Meta CSP (baris 17)**: hapus semua `nonce-__CSP_NONCE__` (nonce placeholder publik = tidak ada nilai keamanan, justru mematikan layout). Directive baru:
  ```
  default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: https:; connect-src 'self' https://hhywrvedlwljawgxzpkq.supabase.co https://raw.githubusercontent.com; font-src 'self'; object-src 'none'; base-uri 'self'; form-action 'self'
  ```
  - `style-src 'unsafe-inline'` → 92 inline style di HTML + 251 di template JS live + `<style>` di window cetak nota (`printer.js`) langsung pulih.
  - `script-src 'self'` (tanpa nonce, tanpa unsafe-inline) → semua JS eksternal aman; konsekuensi: 3 inline script harus ditangani (poin di bawah).
- **Script nonce-replacement (baris 4–8)**: HAPUS — obsolete setelah nonce dibuang (tidak ada dependensi `window.CSP_NONCE` di js/ — sudah diverifikasi grep).
- **Script DEV SW-unregister (baris 46–70)**: pindahkan utuh ke file baru `js/dev-unregister-sw.js`, muat di posisi sama di `<head>` sebagai script eksternal biasa (tanpa nonce). Logika tidak berubah.
- **Script `console.log("Kaki5 ESM loaded")` (baris 650–652)**: HAPUS (dead code).
- **Hapus atribut `nonce="__CSP_NONCE__"`** dari 4 sisa tag script (dexie.min.js, app.js, supabase.min.js, supabase-config.js).
- **Link style.css (baris 43)**: ganti trik mati
  `<link rel="stylesheet" href="css/style.css" media="print" onload="this.media='all'">`
  menjadi `<link rel="stylesheet" href="css/style.css">` (blocking normal — 13 file CSS lain sudah blocking, tidak ada regresi; handler `onload` inline memang diblokir CSP).
- **Bump cacheBust**: `js/app.js?v=66` → `?v=70` (selaras SW v70). Link CSS lain tidak diberi param (jaga cocok dengan daftar precache SW yang tanpa param).

## Risiko & Mitigasi
- **HTML cache-first di SW**: pengguna lama tetap melihat CSP lama sampai SW v70 aktif lalu reload — alur update.js yang sudah ada akan memandu reload. Setelah deploy, verifikasi produksi kasirsolo.app sekali buka + hard reload.
- **Penghapusan inline script**: satu-satunya yang berdampak adalah dev SW-unregister — dipindah bukan dihapus; perilaku dev tak berubah.
- **Rollback**: semua perubahan dalam 5 file kecil + 1 file baru; revert commit tunggal jika perlu.
