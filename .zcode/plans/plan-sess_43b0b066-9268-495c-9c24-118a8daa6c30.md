### P0 — PENCEGAHAN: Drift Detector di `push-beta.ps1` dan `push-live.ps1`

**Tujuan:** Agar snapshot orphan-squash di branch `main` benar-benar identik dengan work tree, sehingga 404 seperti yang baru terjadi tidak akan terulang.

**Desain helper `Test-TreeDrift`** (ditambahkan di kedua skrip setelah `Test-TreeSecret`):

```powershell
function Test-TreeDrift([string]$SourceDir, [string]$TargetDir) {
  $src = & git -C $SourceDir ls-tree -r --name-only HEAD | Sort-Object
  $tgt = & git -C $TargetDir ls-tree -r --name-only main 2>$null | Sort-Object
  if (-not $tgt) {
    Write-Host "     [DRIFT] Target $TargetDir belum punya branch main — lewati cek." -ForegroundColor Yellow
    return $false
  }
  $onlySrc = @($src | Where-Object { $_ -notin $tgt })
  $onlyTgt = @($tgt | Where-Object { $_ -notin $src })
  if ($onlySrc.Count -eq 0 -and $onlyTgt.Count -eq 0) {
    Write-Host "     Drift check OK: $($src.Count) file identik." -ForegroundColor Green
    return $false
  }
  Write-Host "[DRIFT] Snapshot tidak identik antara $SourceDir dan $TargetDir" -ForegroundColor Yellow
  if ($onlySrc.Count -gt 0) {
    Write-Host "  Ada di source tapi TIDAK di target ($($onlySrc.Count) file, max 50):" -ForegroundColor Yellow
    $onlySrc | Select-Object -First 50 | ForEach-Object { Write-Host "    + $_" }
  }
  if ($onlyTgt.Count -gt 0) {
    Write-Host "  Ada di target tapi TIDAK di source ($($onlyTgt.Count) file, max 50):" -ForegroundColor Yellow
    $onlyTgt | Select-Object -First 50 | ForEach-Object { Write-Host "    - $_" }
  }
  return $true   # ada drift
}
```
