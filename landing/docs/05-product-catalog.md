## ➕ Menambah Aplikasi Baru

Ada 2 cara untuk menambah aplikasi baru ke katalog:

### Cara 1: Lewat Admin Dashboard (Disarankan)

1. Buka admin dashboard
2. Masuk ke tab **Katalog**
3. Klik tombol **➕ Tambah Aplikasi**
4. Isi: ikon (emoji), nama, deskripsi, kategori, harga, centang Hot jika perlu
5. Klik **Simpan** pada baris tersebut
6. Refresh landing page — aplikasi baru langsung muncul

### Cara 2: Edit Langsung di Source Code

Edit bagian `DEFAULT_CATALOG` di dalam `<script>` `index.html`:

```javascript
const DEFAULT_CATALOG = [
  // ... aplikasi existing
  {
    id: 'aplikasi_baru',
    icon: '🆕',
    name: 'Nama Aplikasi Baru',
    desc: 'Deskripsi singkat aplikasi baru.',
    price: 300000,
    category: 'bisnis',
    hot: false
  }
];
```

> ⚠️ Cara 2 hanya mengubah default. Jika admin sudah mengedit katalog via dashboard,
> perubahan di source code akan ditimpa saat admin menyimpan.
